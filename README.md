## 📌 Overview
This is my personal portfolio website, designed to showcase my skills, projects, and professional journey. It acts as a centralized hub for recruiters and collaborators to view my work in Web Development, AI/ML, and Open Source.

## 🚀 Features
- ✅ **Responsive Design:** Optimized for seamless viewing on desktops, tablets, and mobile devices.
- ✅ **Dynamic Project Cards:** Interactive displays of my latest projects with live and GitHub links.
- ✅ **Smooth Animations:** Integrated subtle micro-animations for an enhanced user experience.
- ✅ **Optimized Performance:** Fast loading times and deployed globally on Render.

## 📦 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kaushallakshya71-a11y/Portfolio.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Portfolio
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm start
   ```
